# 🔐 Random Password Generator

A simple, modern, and responsive Random Password Generator built using HTML, CSS, and JavaScript. This application generates random passwords with customizable length and character options.

## ✨ Features

- 🔑 Generate random passwords instantly
- 🔠 Include uppercase letters (A–Z)
- 🔡 Include lowercase letters (a–z)
- 🔢 Include numbers (0–9)
- 🔣 Include special symbols
- 🎚️ Customize password length from 4 to 32 characters
- 📋 Copy passwords to the clipboard
- 🔒 Uses the browser's Web Crypto API for secure random number generation
- 📱 Responsive design for mobile and desktop
- 🎨 Modern user interface with a dark gradient background

## 🛠️ Technologies Used

- **HTML5** — Application structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Password generation and functionality
- **Web Crypto API** — Cryptographically secure random number generation
- **Clipboard API** — Copy generated passwords

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all files are in the same folder.
4. Open `index.html` using the Live Server extension.
5. Generate a password and customize it using the available options.

## 💡 How to Use

1. Select your desired password length.
2. Choose which character types to include.
3. Click **Generate Password**.
4. Click **Copy** to copy the generated password.

At least one character type must be selected to generate a password.

## 🎯 Project Objective

This project was created to practice front-end web development, JavaScript event handling, random number generation, and browser APIs.

## 🔐 Security Note

The application uses the Web Crypto API to generate random characters. Password security also depends on password length, character selection, and how the password is stored or shared. Avoid sharing passwords with others.
